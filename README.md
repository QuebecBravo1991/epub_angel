# epub_angel

A Rust tool that takes an ebook in EPUB format, removes all profanity from the text, and outputs a cleaned version of the book.

## Requirements

- [Rust](https://www.rust-lang.org/tools/install) (edition 2024)

## Build & Run

```bash
cargo build
cargo run
```

## Project Structure

```
epub_angel/
├── src/
│   └── main.rs   # Entry point
└── Cargo.toml    # Project manifest and dependencies
```
